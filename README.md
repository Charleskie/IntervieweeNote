# IntervieweeNote

# interviewee目录下主要是各大互联网公司的笔试题代码

# 其他几个文件夹只是一些不相关的测试学习的代码

## 项目结构梳理

- `src/main/java/interviewee/Algorithm`：基础算法练习，比如 KMP、最大公约数、快速排序、区间合并等；常见排序、动态规划、链表、字符串、数组算法分别集中在 `SortAlgorithms.java`、`DynamicProgrammingAlgorithms.java`、`LinkedListInterviewAlgorithms.java`、`StringInterviewAlgorithms.java`、`ArrayInterviewAlgorithms.java`。
- `src/main/java/interviewee/Leecode`：LeetCode 题解集合，按链表、数组、字符串、动态规划、二叉树等主题继续拆分。
- `src/main/java/interviewee/{alibaba,iqiyi,jingdong,meituan,nowcode,pinduoduo,shunfeng,toutiao,wangyi,xiecheng}`：各公司笔试题或在线编程题草稿。
- `src/main/java/interviewee/SQL`：SQL 题目记录。
- `src/main/java/Myschool`：Java 基础学习、异常、图书馆示例等，与面试题主线关系不大。

本次注释整理主要覆盖 `interviewee` 目录下的核心题解方法和辅助方法；`main` 多数是命令行输入或临时调试入口，保留原样。
